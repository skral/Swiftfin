# Concepts

Shared domain vocabulary for this project — entities, named processes, and status concepts with project-specific meaning. Seeded with core domain vocabulary, then accretes as ce-compound and ce-compound-refresh process learnings; direct edits are fine. Glossary only, not a spec or catch-all.

## Apple TV system profile

The Apple TV identity selected through the operating system, intended to provide a separate app storage context and remembered Jellyfin account.

## Jellyfin account

The server-authenticated identity that determines accessible libraries, playback history, and permissions; it is distinct from an Apple TV system profile.

## Local account protection

An additional device-side authentication requirement for opening a saved Jellyfin account, separate from the server login and system-profile selection.
